## 1-1. ★기본 형식은 찾아보기형 (2026-11-16 전환)

```
왜      57초 설명형은 2일에 453회·좋아요 0. 같은 기간 구독 수백 명 채널의 10초 「찾아보세요」형은 10만~36만 회
        시청자는 남의 표본 명반이 아니라 「내 것」을 찾을 때 멈추고, 다시 보고, 댓글을 단다
형태    카드 1장, 10~12초. rows 에 [키, 값, 한마디] 10줄 안팎. 자막은 띄우지 않는다(표를 가린다)
        "rowsHead": ["끝자리","복의 별","복이 들어오는 길"], "note": 표 아래 주석, "dur": 11
        narration 은 한두 문장: 「출생연도 끝자리로 ○○를 찾아보세요. 내 별은 무엇인가요?」
기준    §1-2 의 밝은 판 spec
키      출생연도 끝자리 = 생년 천간 (4갑 5을 6병 7정 8무 9기 0경 1신 2임 3계)
        주석에 반드시 「설(음력 1월 1일) 전에 태어났다면 전년도 끝자리로」
값      Star-Chart src/engine/unhan/UnhanTypes.ts 의 SIHUA_MAP [록, 권, 과, 기] 에서 그대로. ⛔ 지어내지 않는다
        한마디는 그 별의 일반적 성격만. 「대박」「횡재」「망한다」 같은 단정 예언 금지
안전영역 표는 y 1400 위, x 930 왼쪽에서 끝난다 (유튜브가 아래에 제목, 오른쪽에 버튼을 덮는다)
제목    「… | 내 끝자리는? #자미두수 #사주」 처럼 시청자에게 묻는다. 설명 첫머리에 「댓글로 알려주세요」
쉽게    ★표 하나에 개념 하나만. 화록·화권·화과처럼 한 줄로 설명되는 것만 쓴다 (운영자 지정 2026-11-16)
        ⛔ 「그 해 사화와 생년 사화가 겹치는 끝자리」 같은 두 단계짜리는 운영자도 한 번에 못 읽었다. 만들지 않는다
        제목 아래 sub 에는 항상 예시를 넣는다: 「예) 1985년생이면 5 · 1990년생이면 0」
★글과 맞물린다  그날 나가는 네이버 글의 주제에서 「내 것 찾기」 표를 뽑는다. 글과 따로 놀지 않는다 (운영자 지정 2026-11-16)
        결혼운 글 → 띠로 보는 인연의 해(홍란) / 시험운 글 → 끝자리로 보는 인정받는 길(화과) / 신년운세 글 → 끝자리로 보는 복의 별(화록)
        키는 끝자리(생년 천간)나 띠(생년 지지)처럼 시청자가 바로 아는 것만. 12줄 표는 keyW · col2W 로 칸 너비를 맞춘다
        기준(띠) _shorts/spec_mindlumi_20261117-lookup-hongran.json. 홍란 자리는 ZiWeiEngine.ts 의 hredPos 식 그대로
        글 주제에서 한 줄짜리 표가 정말 안 나올 때만 아래 독립 소재를 쓴다
소재    화록(복) · 화권(주도권) · 화과(인정) ·
        명궁 주성별 ○○ · 태어난 달·시로 찾는 명궁 지지 등. 한 번 쓴 표는 index.json 으로 중복을 피한다
```

## 1-2. ★찾아보기형은 눈에 띄는 판(pop)으로 (운영자 지정 2026-11-16)

```
운영자  「숏츠는 눈길을 확 끌어야 한다. 너무 밋밋하게 하지 말고 남들 좋은 건 따라 하자」
본 것   조회 10만~23만짜리 찾아보기 숏츠 5편을 실제로 열어 봤다. 전부 한 장 고정. 강한 색, 큰 제목, 그림(동물·캐릭터),
        출생연도·띠를 그대로 적은 빽빽한 표, 맨 아래 좋아요·댓글 유도. 밋밋한 단색 바탕은 없다
쓰는 법 카드에 "pop": true. rows 는 [그림 자리, 큰 글자, 빨간 한마디, 출생연도 줄] 4칸
        별 표   "faceBase": ".../_shorts/assets/mindlumi/face/" 를 주고 r[0] 에 별 이름 → 우리 캐릭터 얼굴이 줄마다 붙는다
                (얼굴 그림이 없는 별: 타라 천괴 천월 홍란 천희 등. 경양 영성 화성은 크롭이 나빠 쓰지 않는다)
        띠 표   r[0] 에 동물 이모지 한 글자
        title   이모지 + 시청자에게 묻는 훅. 예) 🧧 내가 타고난<br><b>복의 별</b>은?
        pill    👇 내 출생연도 찾기      ask  ❤️ 좋아요 누르고 ○○ 받아가세요      ask2  💬 내 별, 댓글로 남기기
        note    짧게. 「설 전 출생은 전년도 줄」
        맨 위 브랜드 옆에 「자미두수로 보는 내 사주」가 자동으로 붙는다 (운영자 지정 2026-11-16. kicker 로 바꿀 수 있으나 기본값을 쓴다)
        유튜브 설명 첫 줄도 「자미두수로 보는 내 사주 - …」 로 시작한다
        맨 아래에 「📖 더 깊은 풀이 · blog.naver.com/sweetspring978」 이 자동으로 붙는다 (cta.naver 값. 운영자 지정 2026-11-16)
        유튜브 설명에도 mindlumi.ai 링크 아래에 「더 깊은 풀이는 네이버 블로그에서 + https://blog.naver.com/sweetspring978」 을 넣는다
        그날 짝이 되는 블로그 글이 이미 나가 있으면 블로그 첫 화면 대신 그 글 주소를 넣는다
따라 한다  강한 색 · 큰 훅 제목 · 이모지 · 그림 · 좋아요/댓글 유도 · 출생연도 직접 표기 · 가까운 해 순 정렬
⛔        사실이 아닌 것은 안 쓴다. 표의 값은 엔진에서만. 특정 띠·연도에 「대박·횡재가 온다」고 단정하지 않는다
          (훅은 질문으로 세게, 내용은 엔진 그대로)
⛔        어두운 판·밝은 판(light)은 쓰지 않는다
기준    _shorts/spec_mindlumi_20261121-lookup-hwarok.json (별 10줄) · _20261117-lookup-hongran.json (띠 12줄)
유튜브 제목도 훅으로: 「내가 타고난 복의 별은? 🧧 내 출생연도 찾기 #신년운세 #자미두수」
```

## 1-3. 「고객이 무엇을 얻는가」로 말한다 (스토리 점검 2026-11-22, ops/storybrand-check.md)

```
훅        7편 중 3편 이상은 궁금증이 아니라 고객의 문제 한 문장으로 연다. 예) 「올해 유독 힘드셨나요?」 「이직을 망설이고 있나요?」
          주어는 「내 · 나는 · 올해 나는」. 별 이름 · MindLumi · 자미두수로 시작하지 않는다(이야기형은 예외)
두 번째 음성  우리 물건을 소개하지 않고 보는 사람이 얻는 것을 말한다
          narration2  「내 명반에서는 어떻게 나올까요? 네이버에서 마인드루미를 검색해 무료로 확인하세요.」
          ⛔ 「실제 감명 보고서는 이렇게 나옵니다」 로 시작하지 않는다
설명란    주소는 사이트 하나만(https://mindlumi.ai/?ref=shorts). 「더 깊은 풀이는 네이버 블로그에서」 줄은 넣지 않는다
```

## 영화형 배치 "layout": "cine" (2026-11-24 · 11-25 고침, 전설 · 이야기형)

운영자 지적: 전설 편은 설명형 슬라이드가 아니라 예전 영상처럼 영상미 있게(11-24). 그림은 화면 위쪽 절반 크기로, 맨 위는 조금 띄우고, 설명 · 자막은 그 아래에 둬서 겹치지 않게(11-25).
쓰는 법: spec 맨 위에 "layout": "cine". 카드마다 "image" 에 장면 그림(정사각 1080x1080)을 준다. 그림이 있는 카드는 전부 영화형으로 나온다.
- 화면 구성: 위 190px 띄움(연재 이름) → 그림 칸 960px(화면의 50%, 느린 줌/이동) → 글 칸 약 300px(금색 #E8C87A 자막) → 맨 아래 420px 는 쇼츠 단추 · 설명 자리라 비움.
- 바탕에는 같은 그림을 흐리고 어둡게 깔아 위아래가 이어져 보인다. 카드 틀 · 번호 · 진행 점은 없다.
- 첫 카드: title 이 글 칸에 큰 글씨로(자막 숨김). 마지막 카드: "cta": true 를 주면 title + 사이트 주소.
- "ep": "18화 경양" 을 주면 위쪽에 「자미두수 전설 · 18화 경양」.
- 가운데 카드는 title 을 비워 둔다(자막만). 자막은 14자 안팎 · 문장 끝에서 끊긴다. 숫자 표기는 {보이는 글|읽는 말} 그대로.
- image 는 http 주소 또는 remotion/public 아래 경로. 장면 그림은 `_shorts/assets/mindlumi/scene/<이름>/` 에 온다(WEEKLY_RUNBOOK 화요일 줄 「장면 그림 만드는 법」). 그림은 정사각 1K 로 만든다(한 장 약 0.067달러).
- ⛔ 장면 그림이 없으면 영화형을 쓰지 않는다(캐릭터 그림 한 장을 늘려 쓰면 예전 영상의 결이 안 난다).
