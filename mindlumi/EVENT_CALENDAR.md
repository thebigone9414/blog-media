# MindLumi 연중 이벤트 달력과 감명 예시 콘텐츠

운영자 지정 2026-11-18:
- 1년 중 이벤트 시점에는 관련 콘텐츠를 여러 번(최소 주 1회 이상) 올린다. 같은 것을 다시 올리는 것이 아니다. 주제는 같고 내용은 매번 달라야 한다.
- MindLumi 감명 예시를 보여 주면서 「이렇게 감명 결과를 받아 본다」를 알린다. 사람들이 mindlumi.ai 에 와서 결제하게 하는 것이 중요하다.
월요일 주간 제작(`WEEKLY_RUNBOOK.md` [2] 소재)이 이 문서를 읽고 그 주 소재에 반영한다.

## 1. 이벤트 달력

날짜는 해마다 달라진다. 제작할 때 그 해 달력을 WebSearch 로 확인하고 쓴다. 아래 「기간」은 콘텐츠를 내보내는 기간이다.

```
이벤트            기간(대략)                 볼 자리 · 소재                                  맞는 감명 예시
신년운세          11월 중순 ~ 설 연휴 다음 주   그 해 사화(록·권·과·기) × 12궁 · 소한 · 띠          올해 흐름 · 각 영역의 「올해부터 4년 전망」
설(음력 1월 1일)   설 2주 전 ~ 설 다음 주       새해 사화가 실제로 바뀌는 때 · 가족 · 부모궁 · 형제궁   올해 흐름 · 인생 전체 흐름
수능 · 합격 발표   11월 초 ~ 12월 · 2월(정시)   문창 · 문곡 · 화과 · 관록궁                        일과 직장(적성과 성취) · 자녀(공부와 학업)

이사철            2월 ~ 3월 · 9월 ~ 10월       전택궁 · 천이궁                                  돈과 재물(쌓이는가 흐르는가)

## 2. 반복하되 매번 다르게

이벤트 기간 안에서는 매주 글 또는 숏츠가 최소 1편, 그 이벤트를 다룬다. 가장 큰 이벤트(신년운세 · 설)는 주 2편 이상.
같은 이벤트를 다시 다룰 때는 아래 「각도」를 바꾼다. 최근 8주 안에 같은 이벤트 × 같은 각도 × 같은 별·궁 조합을 쓰지 않는다.

```
각도 A  그 해 사화 별 하나 × 12궁 표        (예: 2027 태음 화록 / 거문 화기 / 천동 화권 / 천기 화과 - 별마다 1편)
각도 B  생년 사화 찾아보기                  (출생연도 → 내 별)
각도 C  띠 · 생년으로 찾기                  (홍란 · 천희 등)
각도 D  궁 하나 읽는 법                     (그 이벤트의 궁. 블로그 글에 맞다)
각도 E  감명 예시 발췌                      (§3. 그 이벤트에 맞는 예시의 해당 소제목)
각도 F  인물 명반                          (보도로 생시가 확인된 외국 인물)
각도 G  자주 묻는 것 하나                    (「띠별 운세는 왜 안 맞나」 같은 질문 하나에 답)
```

`mindlumi/index.json` 의 각 항목에 `event`(이벤트 이름)와 `angle`(A~G)을 적는다. 제작 전에 최근 8주를 읽고 겹치지 않게 고른다.
이벤트가 두 개 겹치는 주(예: 11월 = 신년운세 + 수능)는 이벤트마다 1편씩 넣는다.

## 3. 감명 예시 콘텐츠 - 결제로 이어지게 한다

### 재료
사이트 홈의 「예시 보기」에 운영자 본인 명반으로 만든 예시 보고서 7종이 공개돼 있다. 이것만 쓴다. 따로 만들지 않는다.
소제목 단위로 잘라 둔 그림이 `mindlumi/examples/` 에 있다(`<slug>-NN.png`, 목록은 `<slug>-sections.json`).

```
consulting  인생 전체 흐름   8칸   나 자신의 특성 · 긍정적인 사항과 실천 가이드 · 평생 관심 영역 · 타고난 적성 · 경계할 것 …
daehan      10년 흐름        5칸   10년의 환경 변화 · 나에게 나타나는 변화 · 긍정 · 부정과 실천 가이드 · 특이사항
sohan       올해 흐름        5칸   올해의 환경 변화 · 올해 나에게 나타나는 변화 · 긍정 · 부정과 실천 가이드 · 특이사항
jaemul      돈과 재물        7칸   돈을 대하는 태도 · 버는 힘 · 쌓이는가 흐르는가 · 직업과 재물 · 쓰는 방식과 투자 · 4년 재물 전망
iljik       일과 직장        7칸   일을 대하는 자세 · 적성과 성취 · 윗사람 · 동료·아랫사람 · 강점과 과제 · 4년 직업 전망
iseong      사랑과 배우자    6칸   사랑을 대하는 방식 · 배우자는 어떤 사람인가 · 만남의 방식과 시기 · 관계의 과제 · 4년 인연 전망
janyeo      자녀            7칸   자녀와의 인연 · 기질 · 공부와 학업 · 적성과 재능 · 가정 · 4년 자녀 전망
```

사이트 예시가 바뀌었으면 다시 찍는다: Star-Chart 를 `git fetch origin main && git checkout -B main origin/main` · `npm install` 한 뒤
`node mindlumi/_tools/capture_example.mjs <Star-Chart 경로> mindlumi/examples "<상품 이름>" <slug>`. 찍은 그림은 Read 로 열어 확인한다.
(확인 방법: `src/utils/examples/` 의 마지막 커밋이 지난 캡처보다 새것인지 `git log -1 -- src/utils/examples` 로 본다. 2026-11-18 캡처는 c7359dc 기준.)

### 쓰는 법 - 통째로 붙이지 않고, 그 콘텐츠에 맞는 부분만 발췌한다
```
블로그 글      그 글 주제에 맞는 소제목 1~3칸만 넣는다. 글의 설명 → 「실제 보고서에서는 이렇게 나온다」 → 발췌 그림 → 그 대목이 무엇을 알려 주는지 2~3줄
               → 「나머지 칸은 사이트 예시 보기에서 전부 볼 수 있다」 → 무료 맛보기 · 결제 안내
               예) 신년운세 글 → sohan 의 「올해의 환경 변화」「긍정적인 흐름」 또는 jaemul 의 「올해부터 4년 재물 전망」
                   시험운 글 → iljik 의 「적성과 성취의 방식」 · 결혼운 글 → iseong 의 「만남의 방식과 시기」
예시 전용 글   주 1편까지. 「MindLumi <상품 이름> 감명은 이렇게 나옵니다」. 소제목 3~4칸 발췌 + 칸마다 「여기서 무엇을 알 수 있나」.
               보고서 전체를 옮기지 않는다(절반을 넘기지 않는다). 끝에 가격과 「내 걸로 보기」 안내
숏츠           (가) 표 형식: 「<상품 이름> 보고서에 나오는 N가지」 - 소제목을 표의 줄로, 한마디는 그 칸이 알려 주는 것. 마무리 화면 문구는 「예시 보기는 mindlumi.ai」
               (나) ★모든 숏츠에 예시 장면을 넣는다(2026-11-18~). 표 다음에 실제 보고서 화면이 흐르는 장면. 넣는 법은 `WEEKLY_RUNBOOK.md` [9-2] 예시 장면
```
- 숏츠는 전부, 블로그 글은 매주 최소 1편에 감명 예시가 들어간다. 이벤트 기간에는 그 이벤트에 맞는 예시를 쓴다.
- 링크는 `https://mindlumi.ai/?ref=blog` (숏츠 설명란은 `?ref=shorts`). 가격은 그때 `Star-Chart/src/utils/products.ts` 의 값을 읽어 쓴다. 외워 쓰지 않는다.
- 무료로 볼 수 있는 것(원반 · 제2명반 · 인생 총평 맛보기)과 결제하면 받는 것(보고서)을 한 줄씩 나눠 적는다. 과장하지 않는다.

### ⛔ 금지선
- 예시 그림을 고치거나 덧그리지 않는다. 예시에 없는 문장을 예시인 것처럼 쓰지 않는다. 글로 옮길 때는 한 문장 이내로만 인용하고 나머지는 풀어 쓴다.
- 생년월일시를 쓰지 않는다. 누구의 명반인지 밝히지 않는다(운영자가 밝히라고 하기 전까지 「실제 명반으로 만든 예시」라고만 쓴다).
- 실고객 보고서(/r/...)는 어떤 경우에도 쓰지 않는다.
- 자녀 예시는 금지어(요절 · 단명 · 질병 · 장애 · 불효 · 공부 못함 · 자녀 수 단정)가 발췌 칸에 없는지 읽고 쓴다.
- 「이 보고서를 받으면 ~가 된다」 같은 결과 보장, 「대박 · 횡재」 같은 단정 금지. 청약철회 제한 고지를 가리거나 줄여 말하지 않는다.

```
