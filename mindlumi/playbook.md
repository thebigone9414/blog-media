# MindLumi 콘텐츠 플레이북 - 반응을 보고 계속 고친다

주간 발행·속보 작업은 제작 전에 이 파일을 읽고, 끝난 뒤 이 파일에 관찰을 적는다.
목적은 하나다. mindlumi.ai 방문과 결제가 늘어나는 방향으로 매주 조금씩 고친다.
⛔ 조회수만 보고 판단하지 않는다. 기준은 mindlumi.ai 유입(ref=blog · ref=shorts · ref=tistory)이다.

## 1. 지금 쓰는 공식 (같은 교훈이 두 번 나오면 여기로 올린다)

```
글     인물 글은 제목에 인물 이름. 실제 명반 캡처 2장(원반·중첩) 필수
       「자미두수로 ○○운 보는 법」 형태가 검색 노출이 잘 된다 (50편 중 둘뿐인데 둘 다 노출)
       모든 글은 기존 글과 링크로 잇는다
그림   ⛔ 인포그래픽·명반 캡처를 올릴 때 aiGenerated 를 붙이지 않는다 (media_from_url 에 aiGenerated: false 또는 생략)
       붙이면 네이버가 그림 오른쪽 아래에 「AI 활용」 딱지를 단다. 운영자가 원하지 않는다 (2026-11-15)
       코드로 그린 도표와 사이트 화면 캡처는 생성형 AI 그림이 아니므로 표시 대상이 아니다
       ※ 생성형 AI 로 만든 사진·일러스트를 쓰게 되면 그때는 표시한다. 영상의 합성 음성 표시(containsSyntheticMedia)는 그대로 둔다
       ※ update_post 로 옵션을 보낼 때 tags 와 seoKeywords 를 빼면 지워진다. 항상 같이 보낸다
영상   ★기본 형식은 찾아보기형: 10~12초, 표 한 장, 시청자가 자기 출생연도 끝자리(또는 띠·월)를 찾는다 (2026-11-16 전환)
       제목과 설명은 시청자를 지목해 묻는다: 「… | 내 끝자리는?」 「댓글로 알려주세요」
       표의 값은 엔진의 실제 표(SIHUA_MAP 등)에서만 가져온다. 「대박」「횡재」 같은 단정 예언은 따라 하지 않는다
       57초 설명형(8카드)은 인물 글이 나가는 주에만 쓴다
       인물 숏폼은 1번 카드와 유튜브 제목이 인물 이름으로 시작한다
       실제 명반의 해당 궁 한 칸을 확대해 증거로 한 장 넣는다 (fit:contain)
       CTA 는 mindlumi.ai 가 주인공. 블로그는 아래 한 줄
       60초 미만. narration 합계 370~400자
```

## 2. 개선 절차 (제작 전에 매번 돈다)

```
① 성과 회수   get_insights (네이버 글 조회 · 유튜브 조회/좋아요) · get_naver_visibility (검색 노출)
              list_replies (댓글). 결과를 mindlumi/analytics.json 에 날짜별로 누적
② 비교        최근 4주 상위 2건과 하위 2건의 차이를 찾는다
              (제목 형태 · 소재 종류 A/B/C · 훅 · 길이 · 이미지 · 발행 시각)
②-2 ★잘 되는 숏츠를 찾아 뜯어본다 (운영자 지정 2026-11-15 - 매주 월요일 필수)
              내 영상끼리만 비교하면 다 같이 못하는 것 중 덜 못한 것을 고르게 된다. 밖에서 실제로 터진 것을 본다
              찾기   uplika search_youtube_videos (없으면 WebSearch). 검색어를 돌려 가며 3~4번
                     사주 · 사주팔자 · 신년운세 · 2027 운세 · 띠별 운세 · 궁합 · 관상 · 타로 · 자미두수
                     최근 30일 · 60초 이하 세로 영상 · 조회수 순. 구독자 대비 조회수가 유난히 높은 것을 우선
                     (구독자 많은 채널의 평범한 영상은 배울 게 없다. 작은 채널에서 터진 것이 공식이다)
              고르기 5~8편. 사주 계열을 최소 4편
              뜯기   편마다 아래를 실제 수치와 문구로 적는다. 「흥미롭다」 「몰입감 있다」 같은 감상은 금지
                     · 첫 1초 화면에 뜬 글자 그대로, 첫 문장 그대로
                     · 훅 유형 (질문 / 숫자 / 단정 / 대상 지목 「○○띠만 보세요」 / 금기 「절대 하지 마세요」 / 반전)
                     · 제목 그대로와 글자 수, 제목 형태
                     · 길이(초), 컷 전환 간격(초), 자막 크기와 위치, 얼굴·캐릭터·텍스트 중 무엇이 화면을 채우는가
                     · 시청자가 「내 얘기」로 느끼게 하는 장치 (띠·생년·월·성별로 지목하는가)
                     · 끝맺음 (댓글 유도 문구 / 다음 편 예고 / 링크 안내)
                     · 조회수 · 구독자 수 · 좋아요 · 댓글 수, 상위 댓글이 무엇에 반응했는가
              비교   같은 항목으로 내 최근 영상 2편을 적어 나란히 놓는다
              뽑기   차이에서 「이번 주에 바로 바꿀 수 있는 것」을 2~3개 뽑는다. 반드시 이렇게 쓴다
                     ✗ 「훅을 더 강하게」                          ← 쓸모없다. 실행할 수 없다
                     ✓ 「1번 카드 title 을 12자 이내 질문형으로. 예: 젠슨 황, 왜 지금 무너졌나」
                     ✓ 「narration 첫 문장을 대상 지목으로. 예: 계묘년생이라면 이 자리부터 보세요」
                     ✓ 「카드당 5초 → 3.5초, 카드 8장 → 10장」
                     각 항목에 근거 영상(제목·조회수)과 내 영상의 현재 값을 같이 적는다
              한계   엔진으로 못 하는 것(얼굴 출연 등)은 「못 함」으로 적고 버린다. 따라 할 수 있는 것만 남긴다
              ⛔     남의 대본·제목을 베끼지 않는다. 구조와 수치만 가져온다. 공포 조장·단정 예언은 따라 하지 않는다
              기록   `mindlumi/shorts-benchmark.md` 맨 위에 날짜와 함께 표로 누적 (영상 · 수치 · 뜯은 것 · 뽑은 것)
③ 반영        이번 제작에 1~2가지만 바꾼다. 한꺼번에 여러 개 바꾸면 무엇이 먹혔는지 모른다
              ②-2 에서 뽑은 것 중 근거가 가장 센 것을 이번 주 영상 3편에 그대로 적용하고,
              다음 주에 그 영상의 조회·시청 지속이 어떻게 됐는지 반드시 되짚는다 (먹혔으면 §1 공식으로, 아니면 버린다)
④ 기록        아래 §3 맨 위에 「날짜 · 관찰 · 이번에 바꾼 것」 1~2줄
⑤ 승격        같은 교훈이 두 번 확인되면 §1 공식으로 올린다. 틀린 걸로 드러난 공식은 지운다
```
